# Qardan Hasan App - Frontend

A modern, clean, and minimal Next.js application built with React and Tailwind CSS.

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `/app`: Contains the App Router routes (login, dashboard, packets).
- `/components`: Reusable UI components (Sidebar, etc.).
- `/pages`: Reserved for Pages Router (currently empty).
- `/services`: API service layers.
- `/utils`: Utility functions and formatters.
- `/public`: Static assets.

## 🛠 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🎨 UI Features

- **Glassmorphism**: Subtle blur and transparency effects.
- **Premium Palette**: Emerald and Slate color system.
- **Responsive Layout**: Sidebar for desktop and mobile-friendly headers.
- **Dark Mode Support**: Fully compatible with system dark mode settings.
